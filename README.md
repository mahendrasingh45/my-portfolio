# Mahendra Kumar — Portfolio
Responsive portfolio built with HTML, CSS and JavaScript.

## Included
- `index.html` — website
- `assets/mahendra-profile.png` — profile image
- `assets/Mahendra_Kumar_Resume.pdf` — downloadable resume

## Preview
Keep the `assets` folder beside `index.html`, then open `index.html` in a browser.

## Deploy
Extract this ZIP and upload the folder to https://app.netlify.com/drop. After publishing, test the resume download and contact/social links.

Some project links open the GitHub profile because exact individual repository links were not confirmed.
